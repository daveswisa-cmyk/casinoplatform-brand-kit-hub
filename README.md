# CasinoPlatform Brand Kit Hub

This repository exposes approved CasinoPlatform logo assets for automated, read-only brand-kit consumption.

Only the public transparent logo variants required by the Brand Kit handoff are published here. The repository must not contain credentials, private project materials, customer information, approval tokens, or assets belonging to another brand.

Consumers should use direct HTTPS links to individual files under `Brand_Kit/Assets/` and validate the corresponding `asset_manifest.json` before use.
